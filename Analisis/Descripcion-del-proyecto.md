
# SERF - Sistema Empresarial de Gestión de Reportes Financieros

## 1. Datos generales

- Empresa: FinanCorp S.A.
- Nombre del sistema: SERF.
- Tipo de proyecto: Aplicación web empresarial.
- Área responsable: Departamento de Tecnologías de Información.
- Modalidad de desarrollo: Individual (pendiente de autorización del docente).

## 2. Descripción del proyecto

FinanCorp S.A. es una corporación multinacional dedicada a la importación y comercialización de productos tecnológicos elaborados en China, como laptops, smartphones, accesorios electrónicos y equipos de redes.

La empresa cuenta con una sede central en España y diferentes filiales en Latinoamérica y Europa.

Actualmente, cada filial administra sus propios registros de ventas e inventarios mediante diferentes formatos y sistemas, lo que dificulta la integración de la información y la elaboración de reportes financieros corporativos.

Ante esta situación, se propone desarrollar SERF, una aplicación web que permita centralizar la información empresarial, gestionar productos, inventarios y ventas, y generar reportes financieros consolidados de manera automatizada.

## 3. Problema identificado

La empresa presenta dificultades para integrar la información de ventas e inventarios de sus diferentes filiales debido a la utilización de sistemas y formatos distintos.

Asimismo, la consolidación mensual requiere validaciones manuales, ocasionando demoras y dificultando la generación de reportes financieros oportunos y estandarizados.

## 4. Solución propuesta

Desarrollar una aplicación web centralizada que permita:

- Registrar y administrar las filiales.
- Gestionar productos importados.
- Controlar los inventarios.
- Registrar y consultar ventas.
- Consolidar información de las diferentes filiales.
- Generar reportes financieros corporativos.
- Administrar plantillas y configuraciones de reportes.
- Proteger el acceso mediante autenticación y autorización.

## 5. Objetivo general

Desarrollar una aplicación web denominada SERF que permita integrar y administrar la información de ventas e inventarios de las diferentes filiales de FinanCorp S.A., automatizando la generación de reportes financieros corporativos mediante la aplicación de principios SOLID y patrones de diseño creacionales y estructurales.

## 6. Usuarios del sistema

- Administrador: administra usuarios, filiales y configuraciones.
- Encargado de filial: registra productos, inventarios y ventas.
- Gerencia corporativa: consulta información consolidada.
- Analista financiero: genera y revisa reportes financieros.

## 7. Tecnologías propuestas

- Java 21.
- Spring Boot.
- Angular 21.
- MySQL 8.
- Figma.
- StarUML.
- GitHub.
- Postman.

## 8. Alcance inicial

La aplicación permitirá administrar la información de las filiales, registrar productos y ventas, controlar inventarios y generar reportes financieros individuales y consolidados.

También incorporará componentes reutilizables mediante patrones de diseño que permitan facilitar el mantenimiento y la ampliación del sistema.
