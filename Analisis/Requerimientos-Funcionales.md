
# 02. Requerimientos funcionales del sistema SERF

## 1. Introducción

Los requerimientos funcionales describen las operaciones y funcionalidades que ofrecerá el Sistema Empresarial de Gestión de Reportes Financieros (SERF).

## 2. Requerimientos funcionales

### RF01. Inicio de sesión
El sistema permitirá que los usuarios ingresen mediante credenciales de acceso.

### RF02. Gestión de usuarios
El administrador podrá registrar, consultar, modificar y desactivar usuarios.

### RF03. Gestión de filiales
El administrador podrá registrar, consultar, modificar y desactivar las filiales de FinanCorp S.A.

### RF04. Gestión de productos
El sistema permitirá registrar productos importados, incluyendo nombre, categoría, descripción, precio y código de identificación.

### RF05. Gestión de inventarios
El sistema permitirá consultar las existencias de productos por filial y registrar movimientos de entrada y salida.

### RF06. Registro de ventas
Los encargados de cada filial podrán registrar ventas indicando productos, cantidades, precios y fecha de operación.

### RF07. Consulta de ventas
El sistema permitirá consultar las ventas realizadas por filial y por periodos determinados.

### RF08. Consolidación de información
El sistema permitirá integrar los datos de ventas e inventarios de las diferentes filiales.

### RF09. Generación de reportes
El sistema permitirá generar reportes financieros por filial y reportes consolidados corporativos.

### RF10. Personalización de reportes
El sistema permitirá construir reportes agregando secciones, tablas y gráficos.

### RF11. Administración de plantillas
El sistema permitirá reutilizar y adaptar plantillas de reportes según las necesidades de cada país.

### RF12. Organización de reportes
El sistema permitirá estructurar los reportes mediante secciones y subsecciones.

### RF13. Personalización adicional
El sistema permitirá agregar características adicionales a los reportes sin modificar su estructura original.

### RF14. Configuración centralizada
El sistema mantendrá una configuración centralizada para ser utilizada por los diferentes módulos de la aplicación.

### RF15. Exportación de reportes
El sistema permitirá generar reportes en formatos preparados para su descarga y envío, como PDF.

## 3. Resultado esperado

Los requerimientos funcionales permitirán que SERF centralice la administración de las operaciones empresariales y automatice la elaboración de reportes financieros corporativos.
